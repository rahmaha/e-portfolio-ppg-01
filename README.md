## 📋 Tentang Portfolio Ini

E-Portfolio ini dibuat sebagai pemenuhan tugas PPG Prajabatan 2026 dalam satu website
yang mencakup tiga komponen ujian sekaligus.

| Tugas | Komponen |
|-------|----------|
| **LK 4** | Profil · Artefak · Lampiran 7 & 8 · Model Guru |
| **UTS** | Analisis artefak per siklus (4 aspek refleksi) · Lampiran · Model Guru |
| **UAS** | Refleksi Akhir PPL · Filosofi Mengajar |
